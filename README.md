# Lavanya Arora — UX/UI Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Before publishing
Search and replace these placeholders in `index.html`:
- `YOUR_EMAIL`
- `YOUR_LINKEDIN`
- `YOUR_GITHUB`
- `YOUR_PORTFOLIO` (or remove the portfolio link if not needed)

Also verify:
- Project dates
- ServiceNow hackathon project name and one-line description
- Whether the SIH and student community entries should remain
- Add Figma case-study URLs when available

## Preview locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Create a GitHub repository and upload these files to its root.
2. In Vercel, select **Add New → Project** and import that repository.
3. For a static HTML site, leave Framework Preset as **Other** and build settings empty.
4. Click **Deploy**. Vercel will provide a public URL.
